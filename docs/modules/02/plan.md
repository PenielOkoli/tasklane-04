# Tasklane — deliverable 2 plan

## Acceptance criteria

- Next.js App Router and TypeScript compile for production.
- Shared task types cover ID, title, description, status, priority, and category.
- Server page supplies typed initial data; client component owns interactive filters and local demo status selection.
- Vercel AI SDK and Groq adapter are installed as the future model integration layer.
- Secrets remain server-only and are not needed for the current UI.
- Architecture notes explain client/server responsibilities and map to the Module 1 product brief.
- A separate GitHub repository is connected to its own Vercel project.

## Boundaries

This stage proves the Next.js/TypeScript foundation. Task movement is local demo state. Persistence, AI requests, streaming chat, structured output, and approved tool calls are later milestones. The same Tasklane visual identity and task model continue forward.
